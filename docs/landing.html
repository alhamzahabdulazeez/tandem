Tandem for Claude Code

Claude Code finishes when it says it is done. Tandem makes it finish when your tests say so, keeps it away from your existing tests and secrets, trims what it reads, and lets you undo a whole request, shell changes included.

/plugin marketplace add alhamzahabdulazeez/tandem
/plugin install tandem@tandem

Node 18+ and git. Works with any model Claude Code points at, including gateways. Turn off any time with TANDEM_HOOKS=off.

What it catches

“Done” while tests failRuns your suite before Claude may finish and sends it back to fix the code, three rounds at most.
Rewriting tests to passTests that existed before the request are append-only. Removed assertions, .skip and .only are refused.
Test output flooding contextEvery failure line kept, the rest summarized, full log on disk. 71% fewer tokens on real runs, 111 of 111 failure lines kept.
Hallucinated packagesInstalls of names that do not exist on npm or PyPI, or that were published days ago, are refused.
Imports that do not resolveFlagged as they are written. Claude cannot finish while one is still missing.
Keys in code and commitsFifteen credential formats and high-entropy assignments, in edits, shell writes and git commit. Never echoed back.
Destructive commandsgit reset --hard, git clean -f, git push, rm -rf of roots, curl | sh, sudo.
Losing the thread after compactionThe request, files changed, refusals and last test result come back after the context is compacted.

Commands

/tandem:undo [n]Put the working tree back to before the last request, including files changed from the shell.
/tandem:redoReverse the last undo.
/tandem:receiptWhat changed, which tests ran, what was blocked.
/tandem:statsTotals for this repository.

Limits

  • On a strong model and ordinary tasks it does not make Claude solve more problems. It changes what happens when things go wrong, and what a session costs.
  • It is not a sandbox. It rules on the actions Claude Code shows it; shell parsing is pattern-based.
  • The finish gate is only as good as your tests.
